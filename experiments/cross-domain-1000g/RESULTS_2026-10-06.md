## Purpose

Restart evolutionary search after the late-September large runs and test whether the current KODOKU core can sustain diverse long-horizon search across unrelated domains.

This is an **offline heuristic stress-run**, not real-world validation. The current public core has no live LLM adapter or external-evidence evaluator, so winners below are search champions under a deterministic multi-objective heuristic only.

## Champions

### First cash / small business
Individual creators; trigger before recurring monthly work; evolve reusable deliverable templates; return a 48-hour small deliverable; measure before/after delta; accumulate ongoing-operation data; minimize user input.

### AI agent reliability
Long-running agents; trigger before high-impact actions; inspect state diffs; return a stop-reason log; measure independent-critic agreement; accumulate failure-history DNA; keep the routing model-agnostic.

### Research discovery
Materials exploration; trigger when results are close; prioritize reproducibility; return a prediction-difference table; measure agreement with external data; accumulate evaluation protocols; freeze reproducible procedures.

### Education
Language learners; trigger immediately after an error; evolve error-pattern DNA; return the next problem; measure retest accuracy; accumulate difficulty calibration; enforce a study-time ceiling.

### Developer tooling
Data developers; trigger on CI failure; diff-centered review; return a reproduction test; measure CI recovery; accumulate dependency history; never log secrets.

### HCI / UI
Long-session workers; trigger after mis-operation; event-driven UI; return a state diff; measure abandonment; accumulate operation-pattern history; minimize input.

### Robotics
Warehouse robots; trigger on communications loss; reuse skill libraries; return a stop decision; measure success rate; accumulate environment-difference data; preserve observability.

### Energy / climate
Data centers; trigger on price change; combine anomaly prediction with efficiency action; return energy-saving candidates; measure CO2 delta; accumulate verified control rules; preserve manual override.

### Local services / public-service-adjacent ops
Welfare-adjacent operations; trigger on inquiry arrival; auto-classify intake; return missing-item notices; measure no-show rate; accumulate demand-by-time models; preserve manual recovery.

### Creative media
Game creators; trigger on series expansion; learn response deltas; return world-model rules; measure revisit rate; accumulate work-specific response logs; keep edits reversible.

### Accessibility
Hearing-support users; trigger when ambient noise rises; multimodal transformation; return short summaries; measure recognition error; accumulate personalized vocabulary; provide offline degradation.

### Metascience / governance

## Observations

The following are **hypothesis-generating observations only** because this run is not fully reproducible from committed artifacts.


- Best final candidate was usually found early (roughly generation 10–30 in most domains).
- The robotics champion appeared much later (~generation 119), showing that longer search can still matter in some landscapes.
- Population diversity did not collapse to one genome; final generations typically retained ~32–44 distinct genomes out of 64 because of outside-bloodline injection.
- The repeated strong motifs across unrelated domains were:
  - event-triggered operation rather than constant prompting
  - measurable before/after evidence
  - explicit stop / rollback / manual-override paths
  - accumulation of failure history, evaluation protocols, or operation logs as durable assets
  - low user-input burden

## Interpretation

The 1,000-generation horizon is useful as a stability test, but this run alone was not enough to choose a universal search schedule. A follow-up falsification benchmark showed that short independent bloodlines dominate on rugged/deceptive surfaces but can fail badly on smooth cumulative surfaces.

The current safer default is therefore a **barbell allocation**:

- keep at least one long lineage,
- spend a large share of the remaining budget on short independent bloodlines,
- retain periodic outside-bloodline injection,
- use cross-seed and cross-evaluator stability before promotion,
- escalate expensive evidence/LLM evaluation only for finalists.

See `../search-budget-benchmark/RESULTS_2026-10-06.md` for the falsification results.

## Next bottleneck

The largest remaining weakness is evaluator quality, not raw generation count. Before treating KODOKU winners as discoveries, add or connect:

1. pluggable LLM evaluator / mutator,
2. external evidence intake,
3. novelty / diversity pressure,
4. cross-seed replication,
5. run persistence with candidate IDs across KODOKU → SECOND → Nilo → NILO-CHECKS.
